# Reels Auto Next (Facebook Reels + TikTok)

Chrome extension (Manifest V3) โดย XMAN Studio

## ฟีเจอร์
- ▶ **เลื่อนอัตโนมัติ** ไปคลิปถัดไปเมื่อคลิปเล่นจบ
- ⏭ **ข้ามโฆษณา** อัตโนมัติ (ตรวจป้าย Sponsored / ได้รับการสนับสนุน / Ad)
- 🚫 **แบนช่อง** — ปุ่มลอยบนคลิป กดแล้วคลิปจากช่องนั้นจะถูกข้ามตลอด (ปลดแบน / ส่งออก / นำเข้า ได้ใน popup)
- 🤖 **ตรวจเนื้อหา AI** — แสดงป้ายบนคลิปที่ติดป้าย AI และตั้งให้ข้ามได้
- ตั้งค่าเวลาหน่วงก่อนเลื่อน และดูสถิติการข้าม

## รองรับ
- Facebook Reels (`facebook.com/reel/...`) — ภาษาไทย / อังกฤษ
- TikTok (For You, Following, หน้าวิดีโอ)

## ติดตั้ง
1. ดาวน์โหลด / clone repo นี้
2. เปิด `chrome://extensions` → เปิด **Developer mode**
3. **Load unpacked** → เลือกโฟลเดอร์นี้
4. รีเฟรชหน้า Facebook / TikTok

## หมายเหตุ
- ตรวจจับ AI ได้เฉพาะคลิปที่แพลตฟอร์ม/ผู้โพสต์ติดป้าย AI ไว้
- ถ้าแพลตฟอร์มเปลี่ยนชื่อปุ่มหรือป้าย แก้ได้ใน `content.js` (`ADAPTERS`, `AD_EXACT`, `AI_EXACT`)
